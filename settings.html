4. Character consistency and art style
With an installed detector, the first sprite becomes an automatic face anchor. The Director's accepted visible expression drives subsequent local edits. Outfit or pose changes require a new base. Detection is not a quality approval. Matching generation presets: background_integrated and sprite_integrated. Transparent sprites require BiRefNet. The shared style applies to all three; camera changes do not regenerate a cached background.

Layers use a dedicated generation preset with up to two characters. Configure a background and transparent sprite workflow first. Waiting runs in the background; scene changes cancel it. The fallback option generates a fresh image immediately if layers are unavailable. Refinement can change clothing details; image quality still needs testing.
